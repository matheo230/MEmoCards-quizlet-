# MemoCards

Un mini-Quizlet local créé en HTML/CSS/JavaScript.

## Utilisation
1. Ouvre `index.html` dans ton navigateur.
2. Crée un dossier.
3. Ajoute tes cartes avec un recto et un verso.
4. Clique sur « Réviser » pour utiliser les flashcards.

## Fonctionnalités
- Dossiers personnalisés
- Création / modification / suppression de cartes
- Mode révision avec cartes retournables
- Sauvegarde automatique dans le navigateur (`localStorage`)
- Export / import des données en JSON
- Mode clair / sombre
- Interface responsive pour téléphone
- Fonctionne sans serveur et sans installation

Les données sont stockées localement dans le navigateur utilisé.
